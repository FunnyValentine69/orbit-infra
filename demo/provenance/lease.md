# Lease lifecycle recording provenance

`docs/assets/demo-lease.gif` is generated by the transactional recorder from `demo/demo-lease.tape` and is never edited by hand.

| Field | Value |
| --- | --- |
| recorded_from | pending |
| generator commit | pending |
| environment | pending |
| pre-open lease status | pending |
| opened generation | pending |
| apply resource count | pending |
| close result | pending |
| final lease status | pending |
| state and lock versions remaining | pending |
| gif sha256 | pending |
| size | pending |
| duration | pending |
| frames | pending |

The recorder validates every section result, the generation transition, owner fencing, the closed terminal state, and zero retained state or lock versions before publishing. Abort recovery is bound to the recording run's owner and generation; claimed, manual-intervention, cleanup-failed, and foreign leases require the manual recovery procedure.
